# **App Name**: PrivacyWeb

## Core Features:

- Tabbed Browsing: Tabbed browsing interface to open, close, and switch between multiple tabs.
- Smart URL Bar: Smart URL address bar with autocomplete, HTTPS lock indicator.
- Navigation Controls: Controls for back, forward, refresh, and home navigation.
- Bookmark Manager: Functionality for bookmarking pages including add/remove bookmarks and organize into folders.
- History: Displays history including view and clear functionality.
- Private Mode: Provides option for private/incognito browsing.
- Ad & Tracker Blocker: Tool which automatically blocks ads and trackers.

## Style Guidelines:

- Primary color: Dark blue (#2E3A87) evoking security and trustworthiness.
- Background color: Very dark blue (#13162D), almost black.
- Accent color: Bright sky blue (#71A3FF) to highlight interactive elements.
- Body: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for headlines or body text
- Headlines: 'Space Grotesk' a proportional sans-serif with a computerized, techy, scientific feel; suitable for headlines
- Code font: 'Source Code Pro' for displaying code snippets.
- Simple, line-based icons to match a clean and modern style.
- Clean, minimal UI inspired by Brave
